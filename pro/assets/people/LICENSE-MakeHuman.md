# MakeHuman body data — CC0

`m04_shapes.bin` (each player's body offsets) is derived from MakeHuman's base mesh (hm08), its targets
(`macrodetails`, `arms`, `legs`, `torso`, `buttocks`, `neck`) and its default rig's vertex weights, as shipped in the
`data/` folder of the MPFB 2.0.18 Blender extension (https://extensions.blender.org/add-ons/mpfb/), by
`pro/tools/body_shapes.py`.

Those core assets are released under CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/):
"All core assets are shared under Creative Commons, CC0" (https://static.makehumancommunity.org/about/license.html;
see also https://static.makehumancommunity.org/mpfb/faq/use_in_closed_source.html). The base mesh file states it
"was explicitly released as CC0 in september 2020" (copyright holders at release: Data Collection AB, Joel Palmius,
Jonas Hauquier).

MPFB's program code (GPL-3.0-or-later) was not run, modified or included; only its data files were read.
